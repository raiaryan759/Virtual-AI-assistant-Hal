# HAL — Virtual AI Assistant 🤖

HAL is a Python-based virtual AI assistant designed to interact with users through voice commands. It combines speech recognition, text-to-speech, and AI-powered responses to create a simple, interactive assistant inspired by tools like Alexa and Google Assistant.

##  Features

*  **Voice Recognition:** Recognizes spoken commands using SpeechRecognition.
*  **Text-to-Speech:** Responds verbally using pyttsx3.
*  **AI-Powered Responses:** Uses the OpenAI API to process questions and generate responses.
*  **Website Automation:** Opens YouTube, Google, and Spotify using voice commands.
*  **Basic Conversations:** Responds to greetings such as "Hi", "Hello", and "Hey".
*  **Python-Based:** Built using Python and beginner-friendly libraries.

## Technologies Used

* Python
* SpeechRecognition
* pyttsx3
* OpenAI API
* Webbrowser

## Getting Started

1. Clone this repository.
2. Install the required Python libraries.
3. Configure your OpenAI API key securely using an environment variable.
4. Run the Python script and interact with HAL using your microphone.

## Security

Never upload your API key to GitHub. Store it securely in an environment variable instead.

## Project Goal

The goal of HAL is to explore voice-controlled applications, AI integration, speech processing, and Python automation while building a simple personal virtual assistant.
